# Projeto Pokémon

Projeto desenvolvido em Java para praticar Programação Orientada a Objetos (POO).

## Conteúdos utilizados

- Classes e objetos
- Atributos privados (`private`)
- Construtores
- Getters e setters
- ArrayList
- Cadastro de Pokémon
- Listagem de Pokémon
- Edição e exclusão
- Estruturas de repetição e condições
